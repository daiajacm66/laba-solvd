# University Prototype – Test Automation Course

This project was developed as part of the **Test Automation Course** at **Solvd Laba**.  
It is intended for educational purposes only and represents a prototype built while learning and applying core Java and backend development concepts.

The main goal of this repository is to demonstrate the understanding of different topics covered throughout the course, rather than to provide a production-ready solution.

## Course Content Covered

### Block 1 – Java Core
- JDK, JRE, and Toolset basics  
- Object-Oriented Programming (OOP): classes and encapsulation  
- Interfaces, `final`, `static`, and polymorphism  
- Exception handling (`try-catch-finally`)  
- Apache Lombok, IDE debugging, and logging  
- Collections and generics  
- Maven project structure  
- Git version control  
- Lambdas, enums, and records  
- Inheritance, abstraction, and method overriding  
- Collection streaming, reflection, and annotations  
- Threads, connection pools, futures, and multithreading  

### Block 2 – Data base
- Database design and schemas using MySQL
